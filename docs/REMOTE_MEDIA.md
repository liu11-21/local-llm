# 用已配對的桌機生成圖片

E3-A、E3-B 交付後，遠端媒體仍支援現有 SD 1.5 圖片流程。E4 的通用影音契約、Wan 2.1／ACE-Step 遠端生成、大檔配額和保留清理策略尚未交付。本機影片／音樂沿用既有 ComfyUI，OpenVINO Adapter 此輪提供文字與 IR 張量推理。

## 桌機

在圖片生成頁準備並啟動受管理的 ComfyUI，確認 SD 1.5 權重及必要節點已就緒，再從「運算環境 → 連接另一台電腦」分享算力。主機的文字引擎和圖片流程分開顯示。Host 在線時，ComfyUI 仍可能未啟動或缺少權重。 [配對方式](REMOTE_RUNTIME.md)

## 筆電

開啟「圖片生成」，選擇已配對並支援圖片的桌機，輸入提示後按「生成圖片」。核對目的地再按「同意並送出」。工作台會等待桌機完成、校驗下載檔案並自動寫入作品庫。預設 SD 1.5 流程可用時，已配對情境需要四次按鈕或選擇操作、一次提示詞輸入，無須填寫技術參數。

如果本機流程尚未就緒且有可用的遠端主機，創作頁會提供明確的主機選項。這個建議依已取得的工作流程狀態判斷。缺少可信的 GPU／VRAM 資訊時不會宣稱某個硬體必定可用。

## 恢復與限制

- 若已送出後斷線，從任務中心或錯誤訊息複製遠端任務 ID，在運算環境的「查詢中斷的遠端任務」重新查詢。已完成的作品會標示「尚未下載」或「已保存到本機」。中斷的傳輸可按「下載或續傳到作品庫」。E1 起，Client 會在提交前保存原提示詞、排除提示詞、Host／Job ID、模型、Workflow、參數及時間。恢復時從本機資料庫還原，生成端回報的種子也會保存。
- Host 重啟會保留已完成任務，並把仍在排隊或執行的工作標成中斷。需要重跑時由使用者再次提交。每個配對裝置最多同時排兩筆，所有裝置合計四筆。主機上的本機與遠端模型共用單一推理槽。
- 遠端目前提供 Stable Diffusion 1.5 的兩個內建圖片工作流程。Host 只接受對應 ID、提示詞和通過 Schema 驗證的參數。PNG 最多 32 MiB，作品依已配對裝置授權，最多兩筆並行傳輸。續傳驗證 HTTP 範圍，整檔驗證 SHA-256 後才發布。
- Host 保留任務中繼資料、完成的文字回答與圖片索引。圖片另存檔案。任務登錄不保存傳入的提示詞或配對金鑰。升級前已提交的作品沒有 Client 提示詞紀錄，補下載時仍能還原模型與參數。E1 升級後的新任務可以還原私人提示詞，SQLite 第 9 版遷移保留原作品及對話。
