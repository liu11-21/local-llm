# 本機資料與保存政策

## E4–E5 保存與清理

SQLite 14 延續資料遷移；推薦憑證只有模型／工作量／政策與效能證據，沒有對話提示詞。Client 媒體工作保存私人 Prompt、Negative、Lyrics、種子與設定，SQLite 為未加密本機資料。Host 的 RemoteJobs 沒有 Prompt／Lyrics 欄位，但 artifact 參數可含 Negative，ComfyUI 的原始檔 metadata／日誌也可能保留輸入內容；外傳前仍須當次同意。

新 Host 結果保留 7 天、8 GiB 配額；Client 片段 4 GiB、過期其他片段清理；不刪 Client 已保存作品、模型與對話。舊 v1 未宣告期限的結果不自動刪除。縮圖最多 16 MiB，源檔身分改變失效，僅清除衍生快取。作品／影片／音訊不作 SQLite BLOB。配對金鑰保持 Windows DPAPI，Token 不放 URL。

[完整保留規則與實作界線](MEDIA_TRANSPORT.md)。完整備份、匯出與自訂保留介面仍非本輪交付，不將檔案保留等同加密。

E3-D 的推薦查詢只讀取本機模型雜湊、裝置、Runtime 及既有量測，不包含 Prompt，不觸發 Benchmark。SQLite 12 的 dispatch_runs 保存模型／引擎 SHA、任務、資源、指定與回報設備、記憶體與狀態，不另存聊天全文。聊天、Agent 與 Team 回答仍依各自既有紀錄保存。

外部 Agent 的工具結果與觀測可能包含本機資料，須在該計畫預覽前確認傳送；工具執行核准不等於網路同意。Team 仍禁止外部成員與本機工具混用。排隊後模型或引擎身分改變會拒絕，沒有改派雲端或偷偷改用 CPU。正式 Worker 的資料目錄鎖避免另一個程序重置活躍任務或使用獨立資源預算。

E3-C 的 SQLite 11 新增 Benchmark Session、Run 和原始量測。固定文字 Prompt 及使用者輸入 Tensor 只保留不可逆工作量雜湊，原始輸入僅在排程中的記憶體與本機子程序 stdin 傳遞，任務結束後釋放。儲存模型 SHA-256、OS、裝置名稱／ID、驅動、後端版本、輸出摘要／雜湊和效能數值，不保存生成全文。錯誤使用固定代碼，避免模型／插件例外夾帶內容。

使用者主動匯出的 JSON／CSV 位於資料目錄 exports/benchmarks，JSON 包含環境身分與原始量測，分享前可自行檢查。刪除歷史只刪 SQLite 對應列，既有匯出檔案與備份副本仍需自行管理。Benchmark 不傳送外部服務、不自動上傳、不自動重跑。

對話、作品提示詞、遠端圖片恢復紀錄及 OpenVINO 執行證據保存在本機 SQLite／檔案。SQLite 的 TEXT 欄位目前未加密。資料主要受 Windows 帳戶與作業系統檔案存取控制保護，備份軟體、共用帳戶或具有檔案權限的其他程式仍可能讀取。

平台未主動同步這些資料。外部文字或遠端圖片任務沿用目的地與費用確認。OpenVINO 使用本機模型，提示詞經程序 stdin 傳遞，沒有放進命令列，後端例外以固定訊息回報，執行證據不保存原始輸入。文字回答與提示詞仍會依一般聊天流程保存。

對話可從聊天頁刪除。OpenVINO 進階區可清除該引擎的執行紀錄，這是 SQLite 的邏輯刪除，WAL、系統備份和磁碟副本可能仍保留歷史。使用者應依自己的備份政策管理副本。移除可選 Runtime 保留模型、編譯與下載快取、對話及執行紀錄，避免把環境管理當成使用者資料刪除。

E4 已實作遠端影音期限與配額；更完整的匯出、備份與自訂隱私設定仍待後續工作。現階段保留既有作品原檔與設定管理。配對金鑰沿用 Windows DPAPI，資料庫內容與這類憑證的保護方式分開呈現。
