# 本機資料與保存政策

對話、作品提示詞、遠端圖片恢復紀錄及 OpenVINO 執行證據保存在本機 SQLite／檔案。SQLite 的 TEXT 欄位目前未加密。資料主要受 Windows 帳戶與作業系統檔案存取控制保護，備份軟體、共用帳戶或具有檔案權限的其他程式仍可能讀取。

平台未主動同步這些資料。外部文字或遠端圖片任務沿用目的地與費用確認。OpenVINO 使用本機模型，提示詞經程序 stdin 傳遞，沒有放進命令列，後端例外以固定訊息回報，執行證據不保存原始輸入。文字回答與提示詞仍會依一般聊天流程保存。

對話可從聊天頁刪除。OpenVINO 進階區可清除該引擎的執行紀錄，這是 SQLite 的邏輯刪除，WAL、系統備份和磁碟副本可能仍保留歷史。使用者應依自己的備份政策管理副本。移除可選 Runtime 保留模型、編譯與下載快取、對話及執行紀錄，避免把環境管理當成使用者資料刪除。

E4 的遠端影音檔案保留期限和配額策略，以及更完整的匯出、備份與隱私設定仍待實作。現階段保留既有作品原檔與設定管理。配對金鑰沿用 Windows DPAPI，資料庫內容與這類憑證的保護方式分開呈現。
