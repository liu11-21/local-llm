# 第一次使用 Local LLM

新資料夾找不到文字引擎與 GGUF 時，首頁會開啟「開始使用」。也可以從首頁重開「新手引導」，或選「略過引導」。

1. 按「開始使用」，查看工作台實際取得的 CPU、RAM、磁碟及 GPU 資料。沒有取得的數值會標示未知。
2. 按「選擇用途」，選「文字聊天」。
3. 檢閱一至兩個本機候選模型。已有模型優先，未安裝時優先考慮適合目前資源的輕量模型。已配對且可接收文字工作時，也可選擇主機模型。
4. 按「一鍵準備」下載需要的文字引擎或固定來源模型。準備會沿用任務中心的安裝與下載。網路中斷可重試，已完成的安裝會從實際檔案重新辨識。若已有引擎與模型，直接開始聊天。
5. 按「開始第一次聊天」，輸入訊息並送出。成功保存後，引導顯示「第一項任務已完成」。

新裝且需要下載的正常路徑是六次按鈕操作及一次提示詞輸入。準備階段不必跨頁。無須輸入引擎路徑、顯示卡、命令或模型下載網址。只有選擇遠端時，需要另外核對資料傳送目的地。

引導保存目前用途、步驟及所選運算環境，重新開啟會接續中途步驟。這些介面偏好不含憑證。圖片、影片和音樂選擇會直接進入創作頁內的 ComfyUI 準備。CPU 仍可用於輕量模型，能否載入則取決於執行當時的資源和 Windows 原則。
