No application or external signing request is authorized by the Web migration. The unsigned Desktop policy below is retained as historical context; see [Web compatibility](docs/WEB_COMPATIBILITY.md).

Canonical policy and proposed Authors／Reviewers／Approvers: [docs/CODE_SIGNING_POLICY.md](docs/CODE_SIGNING_POLICY.md). All named roles and MFA evidence remain unconfirmed. No production signing token is configured by this change. The review-only workflow is disabled unconditionally.
